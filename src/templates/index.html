Telegram API Bilgileri (API ID, API Hash) Nasıl Alınır?
  1. İlk olarak my.telegram.org web adresine gidin.
  2. Telegram telefon numaranızı uluslararası formatta (örn: +905XXXXXXXXX) yazarak giriş yapın.
  3. Telegram uygulamanıza gelen giriş kodunu web sayfasına yazın.
  4. Karşınıza çıkan menüden API development tools seçeneğine tıklayın.
  5. Yeni bir uygulama oluşturma formunda App title ve Short name alanlarını doldurun (örn: "MedyaPanel" yazabilirsiniz). Diğer alanları boş bırakabilirsiniz.
  6. Uygulamayı oluşturduktan sonra ekranda yazan App api_id (sayılardan oluşur) ve App api_hash değerlerini kopyalayarak yukarıdaki alanlara girin.
